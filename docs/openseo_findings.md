## Implications (for the scoring phase)
- Highest opportunity: India race/event queries (high volume, low KD, weak SERPs) paired with a race training plan; marathon/half/10k plan pages; pace calculator and marathon pace calculator as tool pages; how to run faster / build endurance / start running as guides.
- Competitive: shoes (high advertiser competition), generic "running app" (Strava and big apps).
- Positioning only: AI coach, adaptive plan, HRV, missed-training. Low volume now; keep for later and brand terms.

## Takeaways for scoring
1. Best fit: India race and event cluster. Large volume, KD 0-18, results are aggregators, Facebook and stale pages, and nobody offers training plans per race. Orka already has `/races/[slug]` pages.
2. Tool pages: marathon pace calculator and heart rate zone calculator have small sites ranking. Orka's existing predictor and fueling tools can compete.
3. Low-competition guides: how to improve running stamina, how to run faster, how to prepare for a marathon. Weak SERPs. Orka needs real expertise content here.
4. Avoid for now: generic plan terms led by Hal Higdon/Nike/Runner's World, running pace calculator, what is hrv, shoes, brand apps.
5. Positioning terms (ai running coach, strava alternative, runna alternative) have low volume today. Comparison posts by small AI-coach sites show competitors are already using them.
